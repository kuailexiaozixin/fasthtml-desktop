## 一、系统上下文与边界

### 系统定位

fasthtml-desktop 应用的上下文是固定的：

```
┌─────────────────────────────────────────────┐
│                 运行环境                       │
│  ┌───────────────────────────────────────┐   │
│  │    fasthtml-desktop EXE                │   │
│  │    ┌─────────┐  ┌──────────┐          │   │
│  │    │FastHTML │  │pywebview │          │   │
│  │    │本地服务  │  │桌面窗口   │          │   │
│  │    └────┬────┘  └──────────┘          │   │
│  │         │                             │   │
│  │         ▼                             │   │
│  │    ┌──────────┐                       │   │
│  │    │ 模块层    │                       │   │
│  │    │(业务逻辑) │                       │   │
│  │    └────┬─────┘                       │   │
│  └─────────┼─────────────────────────────┘   │
│            │                                  │
│  ┌─────────▼──────────┐  ┌───────────────┐   │
│  │  本地文件系统        │  │  操作系统      │   │
│  │  (Excel/CSV/PDF等)  │  │  (WebView2等) │   │
│  └────────────────────┘  └───────────────┘   │
│            │                                  │
│  ┌─────────▼──────────┐                       │
│  │  外部网络（可选）    │                       │
│  │  HTTP API / LLM    │                       │
│  └────────────────────┘                       │
└─────────────────────────────────────────────┘
```

### 边界定义

| 在系统内部 | 在系统外部 |
|-----------|-----------|
| FastHTML 路由与组件 | 用户（通过 pywebview 窗口交互） |
| pywebview 桌面壳 | 本地文件系统中的数据文件 |
| uvicorn HTTP 服务 | 操作系统 WebView2 运行时 |
| 本地 SQLite 数据库 | 远程 HTTP API（按需调用） |
| 业务逻辑（数据处理/Agent 推理等） | LLM 服务（通过 HTTP 调用） |

### 架构约束（不可变）

这些是 fasthtml-desktop 技能的技术约束，任何架构设计必须在这些约束内进行：

1. **单进程**：所有逻辑运行在同一进程中，无微服务、无独立子进程
2. **双线程**：uvicorn（HTTP 服务线程）+ pywebview（GUI 事件循环线程）
3. **本地优先**：数据默认存本地，网络调用是可选的
4. **CSS/JS 必须内联**：打包后外部文件路径映射不可靠
5. **`console=True`**：用户需要看到启动日志
