## 十七、MVP 边界表

在项目启动时（需求澄清之后，编码之前），明确以下两张表：

### MVP Includes

| 功能 | 分类 | 完成标准 |
|------|------|---------|
| 选择文件夹 | 核心 | 用户可通过文件对话框选择目标文件夹 |
| 预览重命名 | 核心 | 用户能看到更改前后的文件名列表 |
| 执行重命名 | 核心 | 文件名被实际修改 |
| 结果反馈 | 核心 | 重命名完成后显示结果 |

### MVP Excludes

| 功能 | 推迟版本 | 推迟原因 |
|------|---------|---------|
| 撤销操作 | v2 | 需要操作历史记录表和日志 |
| 批量匹配规则（正则） | v2 | 需求待确认 |
| 主题切换 | v3 | 不影响核心功能 |
| 多语言 | v3 | 只有一个用户 |
