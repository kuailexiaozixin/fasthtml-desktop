# FastFPA capabilities

- Full monthly P&L, balance sheet, and indirect cash-flow planning.
- Actual, Budget, Baseline, Upside, and Downside scenario comparison.
- Revenue, margin, workforce, operating cost, working-capital, capex,
  depreciation, debt, interest, tax, retained-earnings, and cash drivers.
- Deterministic statement integrity checks and variance analysis.
- FastERP, FastHRM, and FastCRM synthetic API refresh with explicit fallback.
- FastSheets workbook export, FastInsights handoff, and FastOffice suite entry.
- Department workflow and audit events.
- Read-only, grounded xAI explanations and scenario drafting.
- Public FastAPI developer surface under `/api/v1`.

The synthetic model can be rebuilt with:

```bash
.venv/bin/python seed.py
```
