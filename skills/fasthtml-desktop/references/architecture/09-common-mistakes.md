## 九、常见架构错误

| 错误 | 表现 | 修复 |
|------|------|------|
| 服务层返回 HTML | service 中 import Div | 服务层只返回数据结构 |
| 路由层包含业务逻辑 | route 函数里写 50 行数据处理 | 提取到 service |
| 不画业务流直接写代码 | 边写边想，发现漏了失败路径 | 先列操作路径再写代码 |
| 数据库表没有索引 | 按日期筛选时越来越慢 | 根据读写路径加索引 |
| 接口没类型注解 | 调用时猜参数类型 | 加上完整类型注解 |
| 在不该合的时候耦合 | Agent 代码里 import Div、H1 | Agent 层与 UI 层彻底分离 |
