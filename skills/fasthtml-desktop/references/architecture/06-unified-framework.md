## 六、统一架构框架

fasthtml-desktop 使用统一的架构框架，不因项目规模而改变。所有项目共享相同的架构维度（上下文、业务流、模块、数据、接口），仅根据业务场景选择不同的架构类型。

| 维度 | 统一内容 |
|------|---------|
| **系统上下文** | 始终明确定义系统边界和外部依赖 |
| **核心业务流** | 始终列出主路径、异常路径、边界路径 |
| **模块分解** | 始终使用 routes/services/models 三层 + 可选扩展模块 |
| **数据架构** | 始终根据读写路径设计数据模型 |
| **接口设计** | 始终有类型注解和层间契约 |
| **图生成** | 复杂交互必须出图 |
