## 十三、存储选择表

### 什么数据放哪里

| 数据类型 | 存储方式 | 适用场景 | 不适用场景 |
|---------|---------|---------|-----------|
| **结构化业务数据** | SQLite（Fastlite） | 任务列表、操作记录、配置表 | 大文件、二进制 |
| **应用配置** | `config.json` 或环境变量 | API Key、用户偏好、界面设置 | 需要事务或查询的结构化数据 |
| **大文件** | 用户指定路径 | 导入的 Excel/CSV、导出结果 | 需要随机访问或索引的数据 |
| **日志** | 轮转日志文件 | 运行记录、调试信息 | 需要结构化查询的数据 |
| **临时缓存** | Python tempfile | 下载的临时文件、中间结果 | 需要持久化的数据 |

### 选择原则

```python
# 默认选 SQLite（Fastlite）——它覆盖 90% 的场景
# 只在确定 SQLite 不适用时才换其他方案

# 适合 SQLite 的信号：
# - 数据有固定结构（表、字段、类型）
# - 需要按条件查询（WHERE、ORDER BY）
# - 需要事务（要么全成功、要么全失败）
# - 数据量 < 1GB

# 不适合 SQLite 的信号：
# - 数据是纯文件（PDF、图片）→ 存路径，文件放本地
# - 数据需要频繁全量读写 → 考虑 JSON/CSV 文件
# - 数据量巨大 > 10GB → 这不是 fasthtml-desktop 的适用场景
```
