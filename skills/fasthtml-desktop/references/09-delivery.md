# 交付（⑨）

> 对应工作流 ⑨ 交付。填写交付清单 → 说明产物位置、用法、退出方式 → 交付确认。

## 交付清单要点

完整清单见 `docs/delivery-checklist.md`，至少包含：

- **产物位置**：`dist/*.exe`（Windows）或对应平台产物；源码与 README 位置
- **用法**：双击 `启动.bat`（或对应平台入口）即可独立使用，无需额外配置
- **退出方式**：窗口关闭即退出（uvicorn 线程 daemon）
- **测试证据**：pytest 全绿 + 机器视觉质检通过（ui_window_verify），供用户验收参考

## 双用途 README

README 必须同时服务两类读者：

- **用户说明书**：安装/启动/使用/退出，不出现任何开发术语
- **LLM 克隆说明书**：环境准备 → 依赖 → 启动 → 测试 → 打包，可对照克隆出同等应用

## 启动器交付

一键启动器（`启动.bat` + `launcher.py` + `launcher.json`）完整规则见 `references/04-project-init.md`。

- 用户双击 `启动.bat` 即可独立使用，无需额外配置
- README 可对照克隆出同等应用
- 交付清单已填写测试证据（pytest 全绿 + 机器视觉质检通过）
